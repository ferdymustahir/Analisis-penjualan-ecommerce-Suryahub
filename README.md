# Analisis-penjualan-ecommerce-Suryahub
Proyek ini merupakan hasil analisa data penjualan ecommerce Suryahub Multikategori yang menjual produk elektronik, pakaian, groceries, buku hingga suplemen kesehatan. Untuk meningkatkan penjualan Suryahub menggunakan kampanye digital marketing melalui sosial media, platform iklan digital, dan promosi.
